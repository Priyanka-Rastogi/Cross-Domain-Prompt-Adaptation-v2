# Install with (see ENVIRONMENT.md for why PIP_CONSTRAINT must be cleared):
#   python3 -m venv --system-site-packages .venv

# pins pyarrow==19.0.1 for an unrelated system-level RAPIDS/cuDF stack. That

# override it for this venv's installs only; pip installs pyarrow==24.0.0 and
# huggingface_hub==1.33.0 into this venv's own site-packages without touching
# or uninstalling the system-level pyarrow==19.0.1 (pip refuses cross-env
# uninstalls by design). `pip check` inside this venv reports cudf/pylibcudf
# as wanting pyarrow<20 -- that is the unrelated system RAPIDS stack we never
# import from this project, and is expected/harmless.
